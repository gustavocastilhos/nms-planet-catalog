# 🪐 No Man's Sky - Diário de Bordo

Um sistema simples de cadastro e gerenciamento de planetas (CRUD), desenvolvido em JavaScript puro para auxiliar os exploradores da comunidade do jogo **No Man's Sky**.

---

## 🎯 Objetivo do Projeto

No jogo *No Man's Sky*, o universo é praticamente infinito e os jogadores frequentemente perdem o controle de onde encontraram recursos raros, climas amigáveis ou onde construíram suas bases. 

Este projeto funciona como um **Diário de Bordo Externo**, onde o jogador pode registrar, consultar, editar e excluir informações dos seus planetas favoritos de forma visual e organizada.
